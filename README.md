# NicholasCullenCooper Homebrew Tap

Homebrew tap for installable releases from Nicholas Cooper projects.

## csaw

Install the latest `csaw` release:

```sh
brew install --cask NicholasCullenCooper/tap/csaw
```

Or tap the repository first:

```sh
brew tap NicholasCullenCooper/tap
brew install --cask csaw
```

`Casks/csaw.rb` is generated by GoReleaser from
[NicholasCullenCooper/csaw](https://github.com/NicholasCullenCooper/csaw)
releases.
